# Clint_project_MayEthics

> **MayEthics** — Premium Streetwear Brand Landing Page & eCommerce Web Application.

A modern, responsive web application crafted with React and Vite, featuring smooth animations, interactive product customization, dynamic cart management, and seamless checkout for MayEthics.

---

## ⚡ Highlights

- **Cinematic Background**: Autoplay seamless looping video banner in the Hero section.
- **Collection Showcase**: Interactive grid showcasing various streetwear colorways with dual-view model transitions.
- **Dedicated Product Experience**: Click-through individual product detail view with live colorway switching and size selection.
- **Real-Time Cart & Checkout**:
  - Live quantity adjustment (`+` / `−`) directly inside the sliding cart drawer.
  - Complete delivery checkout modal supporting Dhaka & Nationwide Bangladesh delivery calculation.
  - Instant order placement and receipt confirmation ID.
- **Cross-Device Responsive**: Flawlessly adapts to Ultra-Wide Desktops, Tablets, and Mobile phones.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, JavaScript (ES6+)
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Modern CSS Variables, Glassmorphism & Keyframe Animations)

---

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/tahsin-bit/Clint_project_MayEthics.git
cd Clint_project_MayEthics
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
